# 🍺 Adega Express - Delivery em 15 Minutos

Aplicativo Web e PWA de alta performance para delivery express de bebidas trincando a -2°C.

## 🚀 Funcionalidades
- ⚡ **Entrega Recorde:** Estimativa e pedidos rápidos para entrega em 15 a 20 minutos.
- 📱 **Progressive Web App (PWA):** Instalação direta no celular (iOS/Android) sem necessidade de loja.
- ⬛ **Splash Screen Nativo:** Tela de abertura com a logo DEGA.
- 🛒 **Checkout Integrado:** Finalização de pedidos no próprio site com cálculo de taxa por bairro de Marabá - PA.
- 📋 **Histórico de Pedidos:** Acompanhamento de compras anteriores direto pelo navegador (`localStorage`).
- 🔞 **Controle de Idade (+18):** Verificação legal para venda de bebidas alcoólicas.
- 🎨 **Design System Moderno:** Estética premium, responsividade completa e compatibilidade com navegadores modernos e legados.

## 🛠️ Tecnologias
- HTML5 Semântico & SEO Otimizado
- CSS3 Vanilla (Design System com variáveis customizadas)
- JavaScript Moderno (ES6+)
- Service Worker & Web App Manifest (PWA)
